# Kmeow Engine

[English](README.en.md) | **ភាសាខ្មែរ**

វាយពាក្យខ្មែរដោយប្រើអក្សរឡាតាំង ដូចជា **`sievphov` → សៀវភៅ**។ Kmeow ណែនាំពាក្យពេលអ្នកវាយ ហើយក៏គាំទ្រភាសាអង់គ្លេសដែរ។ ការណែនាំពាក្យអាចដំណើរការដោយមិនចាំបាច់ភ្ជាប់អ៊ីនធឺណិត។

## តើពាក្យណែនាំដំណើរការយ៉ាងដូចម្ដេច?

Kmeow រកពាក្យតាមរបៀបវាយដែលអ្នកបានរក្សាទុក និងក្បួនអានរបស់វា។

| ស្លាក | អត្ថន័យ |
| --- | --- |
| **ត្រូវគ្នា (Match)** | អ្វីដែលអ្នកវាយត្រូវនឹងរបៀបវាយពេញលេញរបស់ពាក្យមួយ។ |
| **បំពេញពាក្យ (Completion)** | ណែនាំរបៀបវាយដែលវែងជាងនេះ ដើម្បីបំពេញពាក្យ។ |
| **កែអក្ខរាវិរុទ្ធ (Correction)** | ណែនាំរបៀបវាយដែលស្រដៀងគ្នា ក្នុងករណីអ្នកវាយខុស។ |
| **ត្រូវជ្រើសដោយផ្ទាល់ (Select explicitly)** | អ្នកត្រូវជ្រើសពាក្យនេះដោយខ្លួនឯង។ |

ពាក្យណែនាំមួយអាចមានស្លាកច្រើន។ ពាក្យខុសគ្នាក៏អាចមានរបៀបវាយដូចគ្នា ដូច្នេះអ្នកអាចឃើញជម្រើសច្រើន។

## ហេតុអ្វីពាក្យខ្លះបង្ហាញមុន?

សម្រាប់ភាសាខ្មែរ Kmeow ផ្ដល់អាទិភាពតាមលំដាប់នេះ៖

1. ពាក្យដែលត្រូវនឹងអ្វីដែលអ្នកបានវាយពេញលេញ។
2. ពាក្យដែលអាចបន្តពីអក្សរដែលអ្នកបានវាយ។
3. ពាក្យដែលអាចជាការកែអក្សរវាយខុស។

ឧទាហរណ៍ ពេលវាយ **`broya`**៖

| ពាក្យ | របៀបវាយ | មូលហេតុ |
| --- | --- | --- |
| **ប្រយ័ត្ន** | `broyat` | រក្សា `broya` ទាំងអស់ ហើយបន្ថែម `t`។ |
| **ប្រសា** | `brosa` | ត្រូវប្ដូរអក្សរមួយដែលអ្នកបានវាយ។ |

ដូច្នេះ **ប្រយ័ត្ន បង្ហាញមុន**។

ក្នុងក្រុមនីមួយៗ ពាក្យដែលប្រើញឹកញាប់ជាទូទៅបង្ហាញមុន។ ពាក្យនៅជុំវិញក៏អាចជួយកំណត់លំដាប់ពាក្យណែនាំបានដែរ។ ពាក្យដែលមិនសូវប្រើនៅតែអាចជ្រើសបាន ប៉ុន្តែពាក្យខ្លះត្រូវការឱ្យអ្នកជ្រើសដោយផ្ទាល់។

ភាសាអង់គ្លេសមានការកែពាក្យដោយឡែក។ ពេលបើកការកែពាក្យអង់គ្លេស **`im` អាចណែនាំ `I'm`**។ បើអ្នកបានរក្សាទុក `im` ជាពាក្យអង់គ្លេសផ្ទាល់ខ្លួន វានឹងរក្សា `im` ដដែល។

## របៀបជ្រើសពាក្យ

ចុចលើពាក្យ ឬចុចគ្រាប់ចុច **Enter** ដើម្បីបញ្ចូលវា។ ប្រើគ្រាប់ចុចព្រួញដើម្បីប្ដូរជម្រើស។

ក្នុង **ជម្រើសវាយអក្សរ (Typing options)** ជ្រើស **ស្វ័យប្រវត្តិ (Auto)** ដើម្បីឱ្យ **Space** បញ្ចូលពាក្យដែលត្រូវគ្នា ឬបំពេញពាក្យដែលអាចបញ្ចូលបាន។ **ដោយផ្ទាល់ (Manual)** រក្សាអ្វីដែលអ្នកបានវាយពេលចុច **Space**។ ពាក្យដែលមានស្លាក **ត្រូវជ្រើសដោយផ្ទាល់** ត្រូវចុចលើពាក្យ ឬប្រើ **Enter**។ **Shift+Space** បញ្ចូលដកឃ្លាធម្មតា។

## កំណត់តាមរបៀបវាយរបស់អ្នក

សម្រាប់ប្រយោគខ្មែរពេញលេញ ជ្រើស **ខ្មែរ → បម្លែង** នៅទំព័រវាយ។ វាយអក្សរឡាតាំងក្នុងប្រអប់ទីមួយ ហើយចម្លងលទ្ធផលជាភាសាខ្មែរពីប្រអប់ទីពីរ។ ដាក់ទស្សន៍ទ្រនិចក្នុងពាក្យនៅប្រអប់ណាមួយ ដើម្បីជ្រើសពាក្យណែនាំផ្សេង។ ជម្រើសរបស់អ្នកត្រូវបានរក្សាទុកពេលកែអត្ថបទ ហើយមានប៊ូតុងត្រឡប់ក្រោយ និងធ្វើឡើងវិញដោយឡែក។

ក្នុង **បញ្ជីពាក្យ (Word list)** បើកពាក្យមួយ ហើយជ្រើស **កែពាក្យ (Edit word)**។ អ្នកអាច៖

- បន្ថែមរបៀបវាយជាអក្សរឡាតាំងដែលអ្នកចូលចិត្ត។
- កំណត់ថាពាក្យនោះប្រើញឹកញាប់កម្រិតណា។
- កំណត់អក្សរកាត់សម្រាប់ពាក្យទាំងមូល ដូចជា `nh` សម្រាប់ ខ្ញុំ។
- លាក់ពាក្យនោះសម្រាប់របៀបវាយណាមួយ។
- បិទរបៀបវាយដែលបង្កើតដោយស្វ័យប្រវត្តិ ដោយទុករបៀបវាយដែលអ្នកបានរក្សាទុកឱ្យនៅដដែល។

ប្រើ **តារាងសំឡេង → អានជា (Sound map → Read-As)** ដើម្បីកំណត់ការអានពាក្យដោយប្រើអក្សរខ្មែរ។ របៀបវាយផ្ទាល់ខ្លួន និងការអានដែលបង្កើតតាមក្បួននៅដាច់ដោយឡែកពីគ្នា។

បើមានរបៀបអានច្រើន សូមបំបែកអក្ខរាវិរុទ្ធខ្មែរដោយសញ្ញាក្បៀស។ របៀបអានទាំងអស់នៅតែបញ្ចូលពាក្យដើម។

ការកែពាក្យត្រូវបានរក្សាទុកក្នុងវចនានុក្រមរួម។ ការជ្រើសពាក្យពេលវាយមិនបន្ថែមរបៀបវាយថ្មីទៅក្នុងបញ្ជីពាក្យទេ។

## សាកប្រើ

ដំឡើង **Node.js 22 ឬថ្មីជាងនេះ** រួចដំណើរការបញ្ជាខាងក្រោម៖

```sh
npm ci
npm run build
npm run manage
```

បើក [localhost:3001](http://127.0.0.1:3001)៖ **វាយអក្សរ** សម្រាប់សាកពាក្យណែនាំ **តារាងសំឡេង** សម្រាប់មើលក្បួន និង **បញ្ជីពាក្យ** សម្រាប់គ្រប់គ្រងពាក្យ។

សម្រាប់ការភ្ជាប់ក្នុងកម្មវិធី សូមមើល [ឯកសារ API](src/public/types.ts)។ បញ្ជាសម្រាប់បង្កើត និងពិនិត្យកម្មវិធីមានក្នុង [package.json](package.json)។

## Hosted website

GitHub Pages serves the browser manager at `https://yarith-dev.github.io/kmeow-typing/`.
Run `npm ci`, `npm run build`, and `node scripts/build-pages.mjs` to generate `.build/pages`.
The Pages workflow rebuilds and deploys on pushes to `main`; repository Pages settings must use GitHub Actions.
The hosted site includes typing, Sound map, word browsing/export and browser-local example edits.
Shared dictionary mutations require the local manager and are unavailable on the static site.
The build copies the exact dictionary pair and Wasm and derives the browsing catalog from that pair.
